# 邱子晨 · 数据分析师求职简历

在线版简历（GitHub Pages）：<https://buyaochixiaoyu.github.io/resume/>

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 在线简历页面，单文件、无外部依赖，可直接在浏览器打开或打印为 PDF |
| `邱子晨-数据分析师-简历.docx` | Word 版简历，便于投递附件 |
| `邱子晨-数据分析师-简历.pptx` | PPT 版简历，便于演示型介绍 |

## 本地预览

```bash
# 直接双击 index.html，或
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> 提示：在浏览器里按 `Ctrl/Cmd + P` 可将在线简历导出为 PDF。
